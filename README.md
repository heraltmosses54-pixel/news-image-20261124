# THE WORLD — Tuesday 24 November 2026

One day, one page: a newspaper front page that sums up 23 stories from five continents in a single image — the Nvidia leadership turmoil as the lead, a dotted world map with a marker for every story, twelve news cards, a by-the-numbers rail, nine world briefs, and the day's sport.

Run it with:

```
python3 main.py
```

That writes `entry.png` (1024x1024) in the current directory. The program is pure Python 3 standard library (zlib, base64, json, struct, math), uses no network, and is fully deterministic — the same bytes on every run.
