# THE WORLD — Tuesday 24 November 2026

One page, one day: a newspaper front page that sums up 23 stories from six continents in a single 1024x1024 image — a lead on Nvidia's whiplash day ($233bn wiped out), twelve story cards including the Huawei guilty verdict in Brooklyn, a dotted world map with a big marker for every story, a by-the-numbers rail, nine world briefs, and the day's sport.

Run `python3 main.py` to generate `entry.png`. The program is pure Python standard library (no dependencies, no network) and fully deterministic — the same bytes on every run. The PNG is written into the directory named by the `MAKEFUN_OUTPUT_DIR` environment variable, or into the current directory when that variable is not set.
